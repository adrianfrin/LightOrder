# 硬件支持与验证

[English](../en/hardware-support.md) · [首页](../../README.zh-CN.md)

设备出现在发现结果中，不代表每项操作都经过实物验证。下表区分实现与已有证据。发行版测试还必须明确二进制版本和运行环境。

| 组件 | 已实现行为 | 证据与限制 |
| --- | --- | --- |
| IT5702 主板灯光 | HID 身份校验，适配器各通道的静态颜色、亮度和关闭；无闪存或保存命令。 | 开发机历史记录包含用户看到变蓝、调暗和关闭的结果。适配器不能读取物理颜色。这不代表所有 IT5702 主板兼容，也不代表新安装包已验证。 |
| ENE SMBus DRAM | OpenRGB SDK v3，按 DRAM 类型及准确的 ENE 描述筛选，校验身份，静态与关闭。 | 历史记录包含两条内存的发现、缓存检查与用户观察。缓存仍属于软件证据。其他内存控制器不在支持范围。 |
| 冷排与机箱风扇 | B650M AORUS ELITE AX ICE、IT8689E 实例 0；冷排控制 0、机箱控制 3。 | 已有短时、有时限的硬件记录只适用于该映射。生产适配迁移使用假后端测试，不能证明安装后服务的硬件行为。 |
| 水泵 RPM | 已验证主板上的只读 `pump.rpm`，对应风扇通道 4。 | 依据历史接线记录与转速测量，尚无肉眼确认物理接口的证据。不写水泵。未知主板保留原始传感器名称。 |
| 其他传感器 | LibreHardwareMonitor 遥测，数值为有限数或 null，带真实采样时间。 | 传感器和驱动可用性随环境变化。缺失值不会替换成虚构数据。 |
| Windows 策略 | 电源计划、进程优先级和支持的亲和性；条件恢复。 | 适配器测试使用内存假实现。真实策略修改及安装服务行为需要独立证据。 |
| 系统信息 | 固定 CIM 查询读取 CPU、主板、内存、显卡、磁盘和系统元数据。 | 查询失败的类别显示不可用。这条信息查询路径不请求序列号、UUID、机器名、用户名或命令行。 |
| 显卡/键盘/鼠标灯光 | 未提供支持的适配器。 | 其他软件可以发现设备，不代表光序支持。 |

## 散热保护与限制

- 会话在 30 分钟或 1,800 次控制更新时结束，以先到者为准。修改运行中的配置保留首次基线和原截止时间，不会自动续期。
- 冷排最低 40%，机箱最低 25%。曲线占空比不下降，含 2–12 个点，以 80°C / 100% 结束。手动模式保留独立高温保护。
- 温度上升立即生效；下降每次更新最多 2°C。启动时从保守的 100°C 开始计算。
- CPU 温度或受控风扇转速缺失/非有限数时尝试恢复。八秒宽限后，受控风扇低于 200 RPM 会触发恢复。
- 两个通道分别尝试恢复，再对比五个相关控制寄存器与基线。回读失败会保留恢复责任并禁用后续控制。
- 控制器租约防止此控制器的实例重叠，但它不是针对所有第三方程序的通用总线所有权机制。

正常释放、EOF 和合作式关闭会尝试恢复。关闭 ACK 先于资源销毁，不是恢复完成的证明。强制结束工作进程、原生 I/O 卡死、系统崩溃、断电与驱动故障均不能保证恢复。**生产适配迁移尚未建立睡眠唤醒、无限期运行或崩溃恢复的验证证据。**

## 正确理解结果

`accepted` 表示命令已接受或已发送。`readbackVerified` 必须说明回读来源：Windows 状态、控制寄存器、后端缓存或其他来源。缓存匹配不能证明实际灯光。`partial`、`failed` 和 `unknown` 必须明确显示，不能汇总为全部成功。`simulated` 只代表模拟测试。

构建、假实现测试、真实 IPC、安装后服务测试、硬件回读和实物观察回答的是不同问题。发行说明应列出实际完成的项目。CI 仅构建并运行无硬件测试，不安装服务、驱动，也不操作硬件。

## 新增支持

请提交控制器与主板型号、固件和软件版本、只读发现结果，以及协议来源和许可证。不要根据相似主板推断风扇或水泵映射。在进行受控硬件验收前，先在适配器中加入白名单与故障测试。详见[贡献说明](../../CONTRIBUTING.md)和[插件指南](plugin-development.md)。
