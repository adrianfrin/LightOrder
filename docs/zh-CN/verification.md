# v0.1.0-preview 验收范围

这是预览版，不代表所有硬件及长期散热场景均已验收。

本机Windows11 x64、B650M AORUS ELITE AX ICE、Ryzen7 9700X、两条ENE RGB内存已验证：

- 受保护Windows服务安装、普通用户界面连接，标准协议发现六个设备/功能入口。
- 主板和两条内存接受静态颜色设置，内存缓存回读匹配；此前用户已确认实际改色/亮度变化。
- 服务内风扇曲线运行有真实读数，释放后基线寄存器验证成功；水泵只读。
- 专门创建的测试进程优先级/亲和性写入、独立回读及恢复成功。
- 服务保存配置、真实WebView2截图、中英文界面及无硬件行为测试。
- 早期11分钟温控记录有643样本、CPU峰值61.5°C，五个寄存器恢复；这是服务迁移前证据，不替代上面的服务专项测试。
- 服务49项、监控模拟后端21项、风扇策略281断言、Windows策略9场景，以及内存/主板协议自测通过。

安装集成发现并修复ZIP目录分隔符和UTF8-BOM清单问题。最终安装器会等待服务快照成功再报告就绪。确切安装包哈希见Release。

未验证：干净系统虚拟机、完整卸载文件清理（当前保留文件）、实机30分钟到期、多小时负载、睡眠唤醒、强杀控制进程、系统崩溃及其他型号硬件。呼吸/彩虹与定时/应用触发自动化尚未实现。安装器未做商业代码签名。
